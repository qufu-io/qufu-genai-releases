# Katkı / Contributing

Hata ve özellik önerilerini GitHub issues üzerinden iletebilirsiniz. Bu depo kaynak kodu deposu değildir; kurulum paketleri ve belgeler içindir. Belge düzeltmeleri için PR açabilirsiniz. Kaynak kodu katkısı için alper@qufu.io ile iletişime geçin.

Ses kayıtları, API anahtarları ve kişisel dosyaları issue/PR içine eklemeyin. Eğitim verisi paylaşımı yalnızca uygulamadaki Destek Ol akışından yapılır.

Author / maintainer: Alper <alper@qufu.io>. AI-assisted development contributor: Codex <codex@openai.com>. Contributions are credited with Co-authored-by commit trailers where applicable.

English: Use issues for bugs and feature requests; documentation PRs are welcome. Source code is private. Never attach recordings, keys or personal files to public reports.
