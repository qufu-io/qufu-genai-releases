# Gizlilik / Privacy

Yerel tanıma sırasında ses, sesten yazıya dönüşüm için buluta gönderilmez. Normal dikte sesleri eğitim arşivine kaydedilmez. Model eğitimi bölümündeki kayıtlar ve kişisel düzeltmeler kullanıcı profilinde tutulur.

Model indirme ve GitHub güncelleme kontrolü internet kullanır. Cihazın online/son görülme durumu için imzalı cihaz kimliği, sürüm ve durum bilgisi qufu.io'ya gönderilir. Sunucu IP adresini görür; bu bildirimler ses, dikte metni, API anahtarı veya kişisel düzeltme kurallarını içermez.

Destek Ol bölümünde yönetici tarafından izin verilen cihazlar, açık paylaşım onayı verilip Gönder'e basıldığında onaylı ses/metin çiftlerini eğitim desteği için gönderir. Taslaklar ve ayarlar gönderilmez. Gönderim geçmişi aynı kaydın tekrar yüklenmesini önler. Pencere kapatılırsa devam eden tek gönderim bitebilir; sonraki gönderimler iptal edilir.

GitHub issues herkese açıktır. Kişisel ses, metin veya günlük dosyalarını herkese açık paylaşmayın. Gizlilik iletişimi: alper@qufu.io.

English: Recognition is local. Updates/model downloads require internet. Device presence includes a signed public identity, app version and online status; the server observes IP addresses. Speech/text contributions are optional and require explicit consent and approved device access. Do not post personal recordings or credentials in public issues.
