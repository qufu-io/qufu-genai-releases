# Güvenlik / Security

Güvenlik açıklarını herkese açık issue yerine alper@qufu.io adresine bildirin. Etkilenen sürümü, yeniden üretme adımlarını ve olası etkiyi belirtin; gerçek kullanıcı verileri veya erişim anahtarları göndermeyin.

Güncel kararlı sürüm desteklenir. Setup kod imzalı değildir; dosya doğrulama hash'leri sürümlerde sunulur. Kontrolsüz veya üçüncü taraf indirme bağlantılarını kullanmayın.

English: Report vulnerabilities privately to alper@qufu.io, including affected version, reproduction steps and impact. Do not include user recordings or credentials. The latest stable release is supported. Installers are currently unsigned.
